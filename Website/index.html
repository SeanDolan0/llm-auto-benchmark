03 Submit

Submit Benchmark Results

Run the evaluation harness on your hardware and submit results via pull request. Every submission records your GPU, VRAM, CPU, RAM, OS, driver, and generation throughput.

  1. 1
    Install the harness

    Python 3.10+. Install with optional backend dependencies.

  2. 2
    Run evaluation

    Supports llama.cpp, vLLM, transformers, or OpenAI-compatible endpoints with profiles (quick, small, medium, standard, extended), or run interactively with slm-bench tui.

  3. 3
    Submit pull request

    Place the generated JSON in Website/data/results/ and open a PR.

# Run standard profile against a local endpoint
slm-bench evaluate \
  --model-id "qwen2.5-coder:7b" \
  --backend openai \
  --endpoint-url "http://localhost:11434/v1" \
  --profile standard \
  --model-ram-gb 4.8 \
  --notes "RTX 3060 12GB, 33 layers on GPU"

# Or launch the interactive Terminal User Interface (TUI)
slm-bench tui

Submission Guide

Submit verified benchmark results via GitHub pull request.

1Fork and clone

Fork the repository to your account, then clone your fork.

git clone https://github.com/<your-username>/llm-auto-benchmark.git
cd llm-auto-benchmark
2Run the evaluation

Run against llama.cpp, vLLM, transformers, or a local OpenAI-compatible server using quick, small, medium, standard, or extended profiles, or run interactively with slm-bench tui.

slm-bench evaluate \
  --model-id "qwen2.5:7b" \
  --backend openai \
  --endpoint-url "http://localhost:11434/v1" \
  --profile standard \
  --model-ram-gb 4.8 \
  --notes "Ollama on RTX 3060 12GB"
3Save the result file

The harness writes to Website/data/results/<model-slug>.json. Verify hardware telemetry and throughput metrics before submitting.

4Commit and open the PR

Branch, commit, push, and open a pull request. CI validates the schema and publishes on merge.

git checkout -b submit/qwen-2.5-7b
git add Website/data/results/Qwen_Qwen2.5-7B-Instruct-GGUF_Q4_K_M.json
git commit -m "feat(benchmark): add Qwen2.5-7B-Instruct evaluation"
git push origin submit/qwen-2.5-7b

Paste a generated result JSON to check required fields before opening a PR.
